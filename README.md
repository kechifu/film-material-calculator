# 膜材用量與成本試算｜公開試用版

獨立靜態網頁，繁體中文介面。無登入、後端、雲端資料庫、第三方程式庫或分析追蹤程式。
本版本已取得專案擁有者的公開發布同意，只發布下述五個靜態檔案。

## 使用方式

1. 開啟網頁即可查看 17 塊**虛構全車面板**的模擬結果。
2. 修改面板寬／長（cm）、每邊餘量與材料單價。表格可以向右捲動查看施工限制與來源。
3. 修改後離開欄位會自動計算，或按「重新計算」。比較可行方案與各幅寬矩形排版。
4. 給店家或朋友看：按「查看／另存 PDF 試算單」，確認目前檢視方案後按「列印／另存 PDF」，在瀏覽器目的地選「另存為 PDF」。採 A4 橫式，建議關閉瀏覽器頁首與頁尾。試算單含採購量、費用、尺寸條件、來源及矩形排版。
5. 下次繼續修改：按「備份案件 JSON」或「下載完整資料 JSON」，再以「匯入 JSON」還原；兩種 JSON 均可匯入，PDF 不能匯回。無來源的舊版 JSON 會標成手動未驗證。
6. 未登記的車型選「其他車型／手動輸入」。新部位尺寸留空，不會猜測尺寸。

「使用這份資料」及「重設模擬資料」會取代當前面板，切換前先儲存輸入。
不自動儲存案件，重新整理回到模擬資料。匯入檔上限 1 MB，每次最多 200 類／500 塊面板。
輸入與匯入檔只在浏览器內處理，工具不送出這些資料。GitHub 等網站主機仍可能留下正常網站存取紀錄。

## 資料可信程度

- **模擬尺寸**：虛構教學示例，不是 Corolla Cross 或其他實車。
- **模板推算・未實測**：目前僅 Corolla Cross 2023 引擎蓋，約 172.06 × 105.75 cm。
  來源：[GravBase / ANJ Graphics v23](https://gravbase.com/products/2023-toyota-corolla-cross-v23)。
  由原 SVG 引擎蓋路徑外接矩形，以 96 px/in 及來源名義 1:20 換算。不是實車量測或曲面展開。
  市場／版本未確認，不代表支援整車。沒有帶入原 SVG、圖稿、輪廓、客戶資料或專案紀錄。
- **手動輸入・未驗證**：未知車型、舊版匯入，或手動改過寬／長；仍保留原參考來源。
- **使用者聲明實測・未複核**：只代表匯入資料的來源聲明，本工具無法複核。

模板初值：未加施工餘量（0）、旋轉／拼接關閉、保留面積及單價未知。
這些不是已確認的施工條件；間隔 1 cm、採購進位 10 cm 也是可修改的試算初值。
模板寬度超過 150 cm，因此原方向、禁止旋轉／拼接會不可行；工具不會自動改動施工限制。
不得據模板推算結果裁切、採購或作正式報價，先由施工方核對尺寸與方向。

## 用量與費用

尺寸不含每邊施工餘量；例如 80 × 100 cm 加每邊 5 cm，矩形為 90 × 110 cm。
採購面積＝卷材幅寬 × 採購長度（向上進位）。材料費依每延米或每㎡單價計算。
排版餘料、施工修邊及拼接額外各自分帳，已包含於採購費用，不重加損耗百分比。
保留面積留空時，完整修邊與淨覆蓋未知；材料量仍可計算。價格留空不推薦最低成本。
只計膜材，不含列印、油墨、施工、運送、稅、起訂費；矩形排版也不代替圖案拼版或接縫施工設計。
沿用 FFDH 棚式與混幅貪婪方案，只推薦已評估候選，不保證全域最佳。

模擬基準：150 cm 單幅 22.35㎡／NT$13,410；混幅 19.17㎡／NT$11,502。
參數或演算法未修改前，載入示例應得到上述结果。

## 最小部署內容

只能將本目錄這五個檔案上傳到**全新的獨立儲存庫**：

- `index.html`：介面、現有計算核心與模擬資料。
- `vehicle-profiles.js`：公開車型／部位參考設定，隨網頁載入。
- `simulation.json`：可下載的模擬输入範例。
- `.nojekyll`：停用 Jekyll 處理。
- `README.md`：本說明。

不要上傳上層目錄、完整 AI 車貼專案、交付包、原始模板、案件 JSON、測試匯入檔或 Git 歷史。
此目錄不依賴 Node、Python、安裝套件或 GitHub Actions 自訂工作流程。

經擁有者確認後：建立獨立公開儲存庫 → 上傳這五檔到 main 根目錄 →
Settings → Pages → Deploy from a branch → main / (root) → Save。
GitHub Pages 會以 `index.html` 為入口。相對路徑 `./vehicle-profiles.js` 適用於儲存庫子路徑。
依據：[GitHub Pages 官方建立說明](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。
此目錄為經核准的公開發布內容，部署後可透過 GitHub Pages 網址試用。

## 逐步新增車型

只修改 `vehicle-profiles.js` 的資料，不必改計算器程式。複製 vehicles 中的一筆，給車型與部位唯一 id。
部位的 panel 與 source 格式可參考現有引擎蓋。單位一律 cm / ㎡，不得填入推測值冒充實測。
沒有可信尺寸的部位先不登記，使用手動輸入；沒有施工條件的初值與限制須寫在 conditionsBasis。
新增量測資料使用 dimensionBasis: `user-measured`，reference 記錄可公開的量測方法／版本，notes 記錄仍未複核。
**勿在公開設定放客戶、車牌、聯絡資料、內部檔案路徑或私人連結。**
設定檔格式錯誤會使頁面無法載入，修改後先用本機預覽核對再發布。
原專案重建本部署包時以私有工作區 `vehicle-profiles.json` 為來源；若手改公開 JS，需同步回來源，避免重建覆蓋。
